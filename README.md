# BIC21203 Web Development - Lab 4a: Client-Side Scripting (JavaScript)

**Name / Student ID:** MUUHAMMAD HAFIDZUL IMAN / AI240026

Three small pages using plain HTML5 and JavaScript (no libraries). Each question has its own folder with `index.html` and `script.js`. Scripts are loaded with `defer`, events use `addEventListener()`, and all text is written with `textContent` (no `innerHTML`).

## How to run
Open the `index.html` inside each folder (`q1/`, `q2/`, `q3/`) in a desktop browser. No server or install needed.

| Question | What it does | Key concepts |
|---|---|---|
| Q1 `q1/` | Click **Change Message** and the paragraph becomes "Hello there!" | `getElementById`, `changeMessage()`, `addEventListener("click", ...)` |
| Q2 `q2/` | `checkInput()` reports if a number is lower than, higher than or equal to 10, or invalid | `trim()`, `Number()`, `Number.isFinite()`, `if...else if...else` |
| Q3 `q3/` | `generateNumbers()` builds an ordered list "The number is 1" to "The number is 5" | `for` loop, `createElement`, `appendChild`, `replaceChildren()` |
